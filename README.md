# Практика работы с Git и JavaScript

Репозиторий содержит учебный проект, созданный в рамках самостоятельной работы.

## Описание кода
В файле `index.js` реализована функция `createPerson()`, которая принимает входные данные пользователя и возвращает структурированный объект `Person` с методом приветствия.

## Как запустить локально
Для запуска демонстрации вам понадобится добавить index.html и подключить туда index.js
